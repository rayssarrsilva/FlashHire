# Writing style · Guia de escrita

Copy this file to `data/writing-style.md` and describe how the candidate writes.
FlashHire sends it to the AI with every open answer and cover letter, and the templates follow it.
Copie para `data/writing-style.md` e descreva como a pessoa escreve.

## Keep · Manter
- Go straight to the point. Short sentences, one idea each.
- Concrete facts: project names, tools, numbers, results.

## Always fix · Sempre corrigir
- Full words, full punctuation, standard grammar.
- No slang, no caps for emphasis.

## Never · Nunca
- Invent facts. Use only the selected résumé and the answer bank.
